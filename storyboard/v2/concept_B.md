# 코디세이 AI 광고 v2 — 컨셉 B 「코디세이 사용 설명서(홈쇼핑 편)」

> 방향: 레퍼런스 변주형. 장삐쭈×스픽 "한국인 99.3%가 모르는 이것"의 병맛 인포머셜 문법을 쓰되, 코디세이 학습자 3인의 극한 상황 릴레이로 만들고 마지막에 셋이 한 팀이 되는 반전으로 동료학습을 심는다.
> 이 문서는 기획만이다. COPA/생성 API는 호출하지 않았고 기존 파일도 수정하지 않았다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 컨셉명 | 코디세이 사용 설명서 (홈쇼핑 편) |
| 로그라인 | 외계인 단체 주문, 서류 산사태, 로봇청소기 군단. 전공도 다른 세 사람이 각자 극한 상황을 AI 한 줄로 푸는 홈쇼핑 광고를 찍다가, 세 번째 사람이 "이건 혼자 못 해요!"라고 외치자 앞의 두 사람이 달려와 한 팀이 된다. |
| 타겟 | 20~30대 비전공자·커리어 전환 희망 성인 (brand.target 그대로) |
| 광고 목적 | 인지 + 관심 유도 (전환은 CTA로 사이트 유입까지만) |
| 핵심 메시지 (1문장) | 전공이 달라도 AI는 시작할 수 있고, 코디세이에서는 혼자가 아니라 동료와 함께 배운다. |
| 슬로건 | **혼자는 오디세이, 같이는 코디세이.** (말장난은 창작 카피이며 작명 유래에 대한 사실 주장이 아니다) |
| 서브 카피 | 나의 AI 여정, 코디세이에서 시작하세요 (v1 슬로건 재사용, 엔드카드 작은 글씨) |
| CTA | codyssey.kr 에서 확인하기 (일정·금액·수치 표기 없음) |
| 총 길이 | 약 52초 (30~60초 충족) |

사용한 브랜드 사실은 storyboard.json brand 섹션 범위뿐이다: 전공·경력 무관, 동료학습+PBL(강의 위주 아님), 장학금을 받으며 배움, 생성형 AI 활용·자동화 중심 과정. 수치·일정·금액·취업률은 어디에도 쓰지 않는다.

톤 점검: brand.tone은 "차분하지만 응원"이다. 병맛은 상황과 형식에만 쓰고, 마지막 15초는 따뜻하게 닫는다. 공포·폭력·욕설은 쓰지 않는다(외계인 손님, 서류, 로봇청소기 모두 무해한 소재).

## 2. 레퍼런스 분석

### 2-1. 핵심 레퍼런스: 장삐쭈×스픽 (https://www.youtube.com/watch?v=7pP0cQRhCQQ)

가져온 것 (포맷·리듬·톤):
- 극한 상황 콜드오픈 → 홈쇼핑 내레이션 "다들 ~하다가 당황했던 경험, 한 번쯤은 있으셨죠?" → "이제 OO와 함께라면 그런 걱정 끝!" 순서.
- 진지한 광고 말투와 황당한 상황의 낙차.
- 3편 반복 후 마지막에 한 번 더 비트는 구조(스픽은 마지막 편에서 기대 배신, 우리는 세 번째 편에서 패턴 자체를 깬다).
- 단순한 2D 플랫 카툰, 과장된 표정, 굵은 하단 자막, 성우 연기 + 효과음 중심의 사운드.
- 반복할수록 빨라지는 리듬(편마다 인포머셜 카드가 짧아진다).

바꾼 것:
| 레퍼런스 | 이 컨셉 |
|---|---|
| 유괴·강도·상어·인체실험 + 욕설 | 외계인 손님·서류 산사태·로봇청소기. 욕설·폭력·위협 없음(미션 유해 콘텐츠 금지, 사내 평가 제출물) |
| 제품 기능 = 영어 한 문장 배우기 | 기능 = AI 한 줄(프롬프트·자동화). 코디세이 과정(생성형 AI 활용·자동화)과 일치 |
| 마지막 편도 같은 틀 + 후기 | 세 번째 편에서 틀을 깨고 앞 두 주인공이 난입. 동료학습이 곧 반전 |
| 후기 패러디("스픽 덕분에 너무 좋아요") | 약관 고지 패러디: "혼자 하지 마세요. 동료학습이니까요." |
| "굿잡!" 확인음 | 자체 확인음: 도장 쿵 + "참 잘했어요!" |
| 마젠타·핑크·남색 팔레트 | 코랄·민트·코발트·해바라기 노랑·크림(복제 방지 + v1 남색·앰버와도 분리) |
| 3~4분 | 52초 |
| 인물 일관성 필요 없음(편마다 다름) | 같은 구조지만 마지막에 3인이 재등장하므로 일관성 전략이 따로 필요(5장) |

복제하지 않는 것: 장면, 대사, 캐릭터, 효과음, 음성 연기는 가져오지 않았다. 형식(문법)만 가져온다.

## 4. 대본 (초 단위)

구분: [상황] 장면 지시 / (캐) 캐릭터 대사(Veo 오디오 우선, 실패 시 TTS 더빙) / (내) 인포머셜 내레이션(TTS) / [SFX] / [자막] 화면 속 큰 글자(ffmpeg).

### 1편 「지수 × 외계인」 0:00~0:16
- 0:00~0:06 (V1) [상황] 한적한 카페. 문이 열리고 보라색 외계인이 10미터짜리 주문서 두루마리를 카운터 위로 굴린다. 지수의 눈이 커진다. (캐) 외계인: "지구식 아메리카노. 은하 전체 몫으로." (캐) 지수: "…전공도 아닌데 어떡해!" [SFX] 두루마리 굴러가는 소리, 작은 UFO 효과음. [자막] 대사 중 강조 단어만("은하 전체 몫!").
- 0:06~0:12 (I1) [화면] 홈쇼핑 스튜디오 카드, 쇼호스트가 제품 소개 포즈. (내) "다들 알바 중에 외계인이 우주 단체 주문을 해서 당황했던 경험, 한 번쯤은 있으셨죠?" (내) "이제 코디세이와 함께라면, 그런 걱정 끝!" [자막] "전공 몰라도 시작!" [SFX] 홈쇼핑 징글.
- 0:12~0:16 (V2) [상황] 지수가 태블릿에 한 줄 입력하자 두루마리가 접혀 작은 컵 열 개로 정리된다. 외계인 감동, 별 모양 눈물. 폭주: 창밖에 외계인 수십 명이 줄 서 있다. (캐) 외계인: "…지구인, 감동이다." [SFX] 도장 쿵 + (내) "참 잘했어요!"

### 2편 「민석 × 서류 산사태」 0:16~0:28 (리듬 빨라짐)
- 0:16~0:20 (V3) [상황] 유리 회의실. 문 열자 서류가 파도처럼 쏟아져 민석이 가슴까지 묻힌다. (캐) 민석: "저 영업팀인데요?!" [SFX] 종이 눈사태.
- 0:20~0:24 (I2) (내) 1편보다 1.3배 빠르게: "다들 퇴근 직전 서류 산사태 만나 당황한 경험, 있으셨죠? 이제 코디세이와 함께라면 끝!" [자막] "AI로 자동화" (brand.what_it_is의 '생성형 AI 활용·자동화 중심'에 해당)
- 0:24~0:28 (V4) [상황] 민석이 한 줄 입력. 서류들이 종이비행기로 접혀 상자로 날아 들어가고 남은 종이는 색종이 폭죽이 된다. (캐) 팀장(화면 밖): "…이걸 오늘?" [SFX] 도장 쿵 + "참 잘했어요!"

### 3편 「도현 × 로봇청소기」 + 반전 0:28~0:47
- 0:28~0:34 (V5) [상황] 전역 첫날, 거실. 로봇청소기 수십 대가 도현을 빙 둘러싸고 일제히 전진. 도현이 경례하다 급히 손을 내린다. (내) 시작: "다들 전역하자마자 로봇청소기 군단에…" → (캐) 도현이 내레이션을 끊는다: "잠깐만요! 이건 혼자 못 해요!" [SFX] 청소기 윙윙, 내레이션 끊기는 테이프 정지음.
- 0:34~0:42 (V6) [상황] 문이 쾅 열리고 지수(앞치마에 커피 얼룩)와 민석(종이비행기 꽂힌 서류가방)이 뛰어든다. (캐) 지수: "같은 조 도현 씨죠? 저희 늦었어요!" (캐) 민석: "셋이 같이 하면 돼요!" 세 사람이 노트북 한 대에 둘러앉아 입력, 청소기들이 줄 맞춰 충전기로 퇴근한다. [SFX] 박수, 도장 쿵.
- 0:42~0:47 (I3) [화면] 쇼호스트 카드, 약관 고지 패러디 자막. (내) "학비·시간 제약 없이 장학금을 받으며 배우는 AI 과정입니다. 단, 혼자 하지 마세요. 동료학습이니까요." [자막] "혼자 하지 마세요" ※ 장학금·동료학습은 brand.usp 문구 그대로.

### 엔드카드 0:47~0:52 (E1)
- [화면] 크림 배경 위 코랄 도장 모양 로고 영역 + 큰 타이포 "혼자는 오디세이, 같이는 코디세이." + 작은 글씨 "나의 AI 여정, 코디세이에서 시작하세요" + "codyssey.kr". 쇼호스트 목소리 마지막 한 줄(내): "코디세이." [SFX] 도장 쿵.
- 로고는 브랜드 정식 로고 자산이 없으므로 이미지 모델로 글자를 생성하지 않고 ffmpeg drawtext로 "CODYSSEY"를 합성한다.

## 5. 톤앤매너

**비주얼**
- 화풍: 2D 플랫 벡터 카툰, 균일하고 굵은 외곽선, 과장된 표정, 그라디언트 없음.
- 색: 코랄 #FF6B5B, 민트 #6FD6B5, 코발트 #2F5BEA, 해바라기 노랑 #FFC933, 크림 #FFF4E0, 선은 짙은 남색 #1B1F3B.
- 질감·조명: 평면 조명, 약한 종이 그레인 오버레이(후합성 가능), 그림자는 단색 블록.
- 렌즈: 가상 카메라는 표정을 잡는 클로즈업·미디엄 위주, 하드컷. 느린 줌/패닝 금지(v1 대비).
- 편마다 배경 색 분리: 1편 크림+민트, 2편 코발트+크림, 3편 노랑+코랄. 마지막 V6은 세 색 혼합.

**타이포**
- 한글 굵은 고딕, 흰 글씨 + 짙은 남색 외곽선, 박스 없음. 화면 중하단 한 줄, 컷 박자에 맞춰 등장·퇴장. 내레이션 문장을 그대로 반복하지 않고 강조 단어만(이중 설명 금지).
- 엔드카드만 큰 타이포.
- 모든 글자는 ffmpeg drawtext. Veo·이미지 프롬프트에는 "no text, no letters" 고정(글자 깨짐 방지).

**사운드**
- 음악: 레트로 홈쇼핑 펑크·브라스 징글, 약 124 BPM, 편마다 키를 반음씩 올림. 마지막 V6에서 따뜻한 밴드 편곡으로 바뀜. 생성 도구: Veo 음악 전용 클립(8초) 1개를 루프·크로스페이드(음악 생성 모델이 없어 대체. 품질 불확실, 아래 리스크 참조).
- SFX: 도장 쿵("참 잘했어요!" 확인음, 3회 반복), 홈쇼핑 징글, 테이프 정지음, 종이 눈사태, 청소기 윙윙, UFO 뿅. 대부분 Veo 클립 오디오를 사용.
- 내레이션: 있음, 단 전체 52초 중 약 15초만. 홈쇼핑 쇼호스트 TTS(과장된 진지함, 편이 지날수록 빨라짐). 캐릭터 대사는 Veo 오디오 우선.
- 믹스: 대사 0dB 기준, BGM -18dB, 내레이션 구간 BGM -24dB 덕킹, 최종 -14 LUFS 근처.

## 8. 일관성 전략 (T2V, 이미지 레퍼런스 불가)

1. 구조로 회피: 3편은 서로 다른 인물·배경이므로 편 간 일관성은 필요 없다(옴니버스, Kalshi 방식).
2. 화풍 고정: 모든 프롬프트 끝에 동일한 STYLE 접미어(외곽선·팔레트·질감). 접미어는 한 글자도 바꾸지 않는다. seed 고정 가능 여부는 COPA 문서 미확인이므로 가능하면 쓰고 아니면 생략.
3. 인물 고정: 캐릭터 블록을 의상 색·소품(앞치마, 사원증, 후드)으로 정의. 얼굴은 점 눈의 단순화된 디자인이라 같은 사람으로 읽히는 폭이 넓다.
4. 유일한 위험 컷 S08(3인 재등장): ①한 클립 안에 3인을 동시 지정, ②의상 색 대비로 구분, ③실패 시 gpt-image-2 단일 이미지(3인이 한 장에 있으므로 일관성 자동 확보) + ffmpeg 약한 줌 + 도장 SFX로 대체.
5. 후처리 통일: 6개 Veo 클립 모두 같은 ffmpeg 필터(eq 채도·대비 소폭, scale lanczos 1080p, fps 24)로 통일. 클립별 색 차이는 허용 범위(편마다 배경색이 다르기 때문)로 둔다.
6. 검수 기준표: ①외곽선 두께, ②팔레트 5색 안, ③화면 속 글자 없음, ④부적절 표현 없음, ⑤대사 인식 가능. 하나라도 어긋나면 재생성 후보.

## 11. 한계

- 이 문서는 기획이다. 프롬프트의 실제 출력, 한국어 립싱크 성공 여부, 클립 길이별 연기 완성도는 생성 전에 확인되지 않았다.
