### 사용하는 브랜드 사실 (전부 brand 섹션 근거)
- 강의 위주가 아닌 동료학습 + 프로젝트 기반 학습(PBL) -> S3 타이포 "동료학습 · 프로젝트", S4 장면
- 전공·경력 무관 -> S3 타이포 "전공 무관"
- 장학금을 받으며 배우는 AI 전문인재 과정(공식 사이트 문구) -> S3 타이포 "장학금"
- AI 네이티브 = 생성형 AI 활용·자동화 중심 -> 외계인이 요구하는 것이 "자동화"인 이유
- 수치·일정·금액·취업률·"칼퇴 보장" 류 결과 약속은 **일절 없음**. 후기 장면은 외계인의 연출된 패러디이며 "※ 연출된 장면" 고지를 넣는다.

## 2. 핵심 레퍼런스 (장삐쭈 x 스픽 "한국인 99.3%가 모르는 이것")

### 가져온 것 (포맷·리듬·톤)
- **콜드오픈**: 설명 없이 말도 안 되는 극한 상황으로 바로 시작 (원본 0:09 유괴 전화).
- **인포머셜 패러디 내레이션**: "다들 ~했던 경험, 한 번쯤은 있으셨죠?" -> "이제 OO와 함께라면 그런 걱정 끝!" (원본 0:19~0:25).
- **기능 한 줄 + 한 문장 가르침 + 확인 효과음** (원본 "렛 마이 썬 고" -> "굿잡!") 구조.
- **배운 걸 써먹다 폭주**: 배운 문장 한 줄이 상황을 과하게 키우는 반전.
- **만족 후기 패러디** ("OO 덕분에 이제 ~할 수 있어서 너무 좋아요").
- **반복의 리듬**: 원본은 3~4편 반복. 본편은 1편으로 압축하되, 컷다운/후속편에서 같은 틀을 변주할 수 있는 구조로 설계.
- 비주얼: 2D 플랫 카툰, 과장된 표정, 원색 대비, 큰 자막. 사운드: 진지한 성우 톤의 황당함, 효과음 중심.

## 5. 톤앤매너

### 비주얼
- **화풍**: 2D 플랫 벡터 카툰. 굵고 둥근 도형, 외곽선 없음 또는 매우 얇음, 그라디언트 없음(약한 비네트만), 단순화·살짝 블러된 배경, 과장된 표정(클로즈업 많이).
- **팔레트(고정)**: 코랄 #FF6A4D / 코발트 #2F4BFF / 버터옐로 #FFD84D / 크림 #FFF6E8 / 잉크네이비 #1B1B3A.
- **조명**: 플랫이므로 그림자는 단색 쉐이프. 홈쇼핑 구간(S3)만 햇살 스타버스트 배경으로 "과잉 밝음".
- **렌즈/카메라 문법**: 크래시 줌, 스냅 줌, 정면 샷. 느린 줌/패닝 금지(v1 탈피). 컷 길이 2~5초.
- **세로 구도**: 인물·글자 안전영역 = 중앙 80%, 하단 15%는 SNS UI 영역으로 비움.

### 타이포 (ffmpeg drawtext, 영상 속 글자 생성 금지)
- 하단 자막 박스 폐지. 화면 중앙의 **키네틱 타이포**: 한 컷 한 단어~한 줄, 컷 박자에 맞춰 팝인/줌펀치.
- 폰트: 굵은 고딕(예: Pretendard ExtraBold 또는 시스템에 설치된 동급 폰트 -> 제작 시 설치 여부 확인), 흰 글자 + 잉크네이비 두꺼운 외곽선, 강조어만 버터옐로.
- 외계인 대사와 후기는 말풍선형이 아니라 큰 자막으로 통합.

### 사운드
- **음악**: 경쾌한 인포머셜/홈쇼핑풍 브라스 팝 스팅어, 약 **128 BPM**(1박=0.47초). 컷 포인트를 2박(약 0.94초) 배수 근처에 맞춤.
  - 별도 음악 모델이 없으므로 BGM은 Veo 클립(S3, S5) 프롬프트에서 "upbeat brass pop, 128 BPM" 으로 요청한 생성음 의존. **품질 불확실** -> 대안은 6번 리스크 참조.
- **SFX(전부 Veo 생성 오디오)**: 착륙 슈웅, 땀방울 보잉, 스타버스트 징글, 도장 쾅(핵심 기억점), 함대 정렬 칙칙, 팡파르.
- **내레이션**: 있음, 단 **2곳만**(S2, S3, S7 짧게). 인포머셜 성우는 TTS(gpt-4o-mini-tts, 지시문으로 "과장되게 진지한 홈쇼핑 성우" 톤 요청). 컷 전반을 설명하지 않고, 자막과 같은 문장을 반복 낭독하지 않는다(자막은 키워드만).

## 8. 일관성 전략 (T2V라 이미지 레퍼런스 불가)

1. **옴니버스/몽타주 논리로 회피**: 클립마다 독립 완결(Kalshi 방식). 인물이 여러 컷에 걸쳐 나오지만 "같은 사람처럼 보이는 정도"로 설계.
2. **인물 토큰 고정**: JIWOO / COLLEAGUE / BLIP 설명문을 모든 프롬프트에 **글자 그대로 복붙**. 단순한 도형 디자인(둥근 얼굴, 단색 의상, 외눈 외계인)이라 변형에도 같은 캐릭터로 읽히게 의도.
3. **화풍 고정**: `STYLE_C` 접미어 + 팔레트 hex 값 고정. seed 고정이 게이트웨이에서 지원되는지 사전 확인(지원 시 모든 클립 동일 seed, 미지원이면 접미어만).
4. **입 없는 외계인**: 립싱크·입 모양 불일치 문제를 디자인으로 제거. 말썽 많은 한국어 발화는 사람 캐릭터 한두 줄로 한정.
5. **후편집 통일**: ffmpeg로 전 클립에 동일 색보정(채도 +, 대비 +, 팔레트 편차 보정), 동일 해상도·프레임레이트(30fps), 오디오 라우드니스 통일. 타이포 폰트·외곽선도 전 구간 동일.
6. **선별 편집**: 클립당 2~3회 생성 후 최선 선택은 쿼터상 어렵다 -> 6개 중 취약 클립(S4, S5)에만 예비 1회 배분.
